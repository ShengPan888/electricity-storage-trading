# 实验演进与选择依据

| 阶段 | 研究内容 | 实际结论 |
|---|---|---|
| Phase 1 | 时间戳、缺失、匿名单位、NC时区与channel审计 | 建立信息边界，不假定发布时间与物理单位 |
| Phase 2 | 官方基线、供需特征分组消融、损失、气象/窗口、模型对照 | 冻结19特征LightGBM＋CatBoost等权融合，点价驱动策略 |
| Phase 2B/2C | 近期窗口、日曲线、气象；关联组消融后固定特征调参 | 改善不稳定，未替换 |
| Phase 3A | IQR、滚动MAD/分位数、Winsorization、Isolation Forest、鲁棒损失与尖峰分类 | 未证实真实脉冲为错误，不为RMSE删除原始尖峰；未替换 |
| Phase 3B | 先信息审计；360次TPE Trial、12个Study、精度/收益独立目标、三种子与策略风险 | 精度候选R²=0.441167，收益下降；保留Phase 2 |
| GitHub增量 | A六时段专家、B近期180天融合、C高低价事件修正 | C的R²=0.450439，收益仍低于冻结模型 |
| Stayfoool完整复现 | 原作者协议核对，再用共同时间切分、训练侧早停、三种子及统一结算比较 | 无先验R²=0.453506、日均收益6800.53，未通过替换门槛 |

## Stayfoool完整复现的范围

固定上游[10864ce](https://github.com/Stayfoool/electricity-ai4s-2026/tree/10864ce6f88941cad54bac83161800bb503ed1f2)，MIT。

- 17列：7预测＋hour/minute/quarter（日内0—95槽）/dayofweek/month/is_weekend及hour、quarter的sin/cos。
- 全历史LightGBM权重0.25，近期180天LightGBM权重0.25，近期180天六时段专家权重0.5。
- 六时段边界`[0,24,40,56,72,88,96]`，共8个LightGBM模型；Huber损失。
- 分别测试无策略先验、固定时窗先验、训练内ON/OFF门控。三者价格相同，动作不同。

原作者协议24项公开指标在预设容差内匹配，公开5664行提交的预测与动作匹配。该检查证明复现一致性，不能证明官方真实收益。

原作者的验证协议与本项目不同，因此另做公平协议：共同5/8/11月、训练末14天早停后重拟合、2026/17/43三种子先平均价格再调度。17列与19列、损失、组件和权重同时不同，完整方案差异不能单独归因于分段。

## 为什么保留失败尝试

供需特征可能没有增量；平均误差改善可能没有改善关键窗口；异常过滤可能删掉真实风险；历史时窗先验可能降低真实收益。记录这些结果能解释模型选择，而不是只展示最高R²。

历史数据已被多轮研究使用。多种子和区块Bootstrap不能消除开发偏差。尚未获得独立新年份、官方隐藏测试标签或实盘调度反馈；Transformer及端到端收益损失不能写成已经完成的工作。
