# 我们怎样把这个项目真正做会

每个问题都对应仓库中能运行的代码或输出，可以按照以下顺序学习。

## 第一课：一笔储能交易

打开合成演示，回答：

1. 电价单位是什么？赛题的power表示什么？为什么当前公式不额外乘0.25？
2. 为什么power为负时SOC增加？
3. 八个充电时段后SOC是多少？为什么不能先放后充？
4. 为什么连续两小时平均价格比单个最高价/最低价重要？
5. 用CSV中16个非零动作手算一笔收益，与程序核对。

对应 `core.py`、`slot_details.csv`、`report.html`。

## 第二课：模型究竟提前知道什么

数据到位后，逐列说清预测值、实际值、可用日期与可用时刻；把一个D+1时段与对应气象发布文件对齐。不能把未来实际值当作特征。

对应未来的 `docs/data_contract.md` 和 `reports/data_audit.md`。

## 第三课：为什么会选这个窗口

解释96点预测怎样变成3321个候选组合；零收益不交易；真实价格为什么不能参与选择；事后最优只是诊断上限。

对应 `optimize_day`、`daily.csv`。

## 第四课：赚了还是亏了

找一个预测选错充电窗口的日子，再找一个放电窗口选错的日子。区分整体价格水平误差与日内相对价差误差。比较模型价格误差和实际收益，理解它们为什么可能不同步。

## 第五课：行业特征是否真的有用

对照同一批验证日期，检查新能源占比、竞价空间、爬坡和气象是否带来稳定收益增量。每个特征都有机制解释，也必须接受负面实验结果。

## 第六课：形成可复现项目

从官方文件到输出CSV，按README完整重跑。将每项项目结论对应到代码、实验记录与局限，确保研究结果可以核对。
