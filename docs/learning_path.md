# 阅读与复现路线

1. 从[首页](../README.md)理解“预测次日实时价→提前制定计划→真实价格结算”。
2. 读[8张技术路线图](architecture.md)，区分输入、标签、决策和Oracle。
3. 对照[数据契约](data_contract.md)与[19特征模型卡](model_card.md)。
4. 读[结果](RESULTS.md)和[实验演进](experiment_history.md)，理解为何没选最高R²。
5. 无数据运行`python run.py demo`及`python run.py research-report`；前者为合成规则演示，后者为真实汇总展示。
6. 持有官方数据后按[研究复现说明](../research/README.md)运行冻结规格，使用新目录。
7. 读[政策对照](policy_alignment.md)，区分竞赛策略与实际申报、调度、结算。

## 面试口径

“先审核次日可用预测与信息边界，排除未来实际值和未确认价格滞后。围绕负荷、新能源及供需候选分组消融，保留19列输入，用LightGBM与CatBoost等权融合预测96点价格。随后穷举3321种合法充放电组合和不交易，以真实价格结算，结合Oracle、捕获率和Regret复盘。后续自动调参与同赛道复现提高了精度，但没通过收益稳定性门槛，因此保留原模型。”

成绩注明“内部历史开发估计、未知赛题尺度、非官方成绩”，不将固定8点动作描述成完整电站实盘调度。
