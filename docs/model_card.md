# 当前冻结模型卡

更新2026-11-09；原运行`phase2_20261108_164706`。后续实验未通过替换门槛，保留该模型。

## 任务与19列输入

预测次日96个15分钟实时电价，输入时间为北京时间。

| 顺序 | 特征 | 计算/来源 |
|---|---|---|
| 1—7 | 系统负荷预测值、风光总加预测值、联络线预测值、风电预测值、光伏预测值、水电预测值、非市场化机组预测值 | 官方预测白名单 |
| 8—11 | hour、minute、dayofweek、month | 目标时间 |
| 12 | slot_id | hour×4＋minute//15 |
| 13—14 | slot_sin、slot_cos | 2π×slot_id/96 |
| 15—16 | weekday_sin、weekday_cos | 2π×dayofweek/7 |
| 17—18 | month_sin、month_cos | 2π×(month−1)/12 |
| 19 | renewable_ratio_candidate | 风光总加预测/负荷预测；分母绝对值≤1e−12返回缺失 |

候选比例的物理含义受匿名缩放影响，不能认定为经核实的物理新能源占比。实际边界、验证真实价格、历史价滞后与NWP均不进入当前矩阵。

## 固定训练规格

| 组件 | 设置 |
|---|---|
| LightGBM | regression_l2；learning_rate=0.05；num_leaves=63；最多1000轮；patience=50；沿用原运行默认随机种子规则 |
| CatBoost | RMSE；depth=6；learning_rate=0.05；最多1000轮；patience=50；random_seed=0；CPU |
| 插补 | CatBoost前median插补＋缺失指示，统计量只由对应训练段拟合 |
| 轮数 | 历史末14天早停，再重拟合完整历史训练段 |
| 融合 | 0.5×LightGBM价格＋0.5×CatBoost价格，先融合再调度 |
| 标签 | 原始A，不修改、过滤、裁剪或插值 |
| 缺失日 | 有效点可用于点模型；收益只评价96点完整日期 |
